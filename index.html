Attention Is All You Need

Abstract

The dominant sequence transduction models are based on complex recurrent or convolutional neural networks that include an encoder and a decoder. The best performing models also connect the encoder and decoder through an attention mechanism. We propose a new simple network architecture, the Transformer, based solely on attention mechanisms, dispensing with recurrence and convolutions entirely. Experiments on two machine translation tasks show these models to be superior in quality while being more parallelizable and requiring significantly less time to train. Our model achieves 28.4 BLEU on the WMT 2014 English-to-German translation task, improving over the existing best results, including ensembles, by over 2 BLEU.

1. Introduction

Recurrent neural networks, particularly long short-term memory (LSTM) and gated recurrent (GRU) neural networks, have been firmly established as state of the art approaches in sequence modeling and transduction problems such as language modeling and machine translation. Numerous efforts have since continued to push the boundaries of recurrent language models and encoder-decoder architectures.

Recurrent models typically factor computation along the symbol positions of the input and output sequences. Aligning the positions to steps in computation time, they generate a sequence of hidden states $h_t$, as a function of the previous hidden state $h_{t-1}$ and the input for position $t$. This inherently sequential nature precludes parallelization within training examples, which becomes critical at longer sequence lengths, as memory constraints limit batching across examples.

In this work we propose the Transformer, a model architecture eschewing recurrence and instead relying entirely on an attention mechanism to draw global dependencies between input and output. The Transformer allows for significantly more parallelization and can reach a new state of the art in translation quality after being trained for as little as twelve hours on eight P100 GPUs.

2. Scaled Dot-Product Attention

An attention function can be described as mapping a query and a set of key-value pairs to an output, where the query, keys, values, and output are all vectors. The output is computed as a weighted sum of the values, where the weight assigned to each value is computed by a compatibility function of the query with the corresponding key.

We call our particular attention "Scaled Dot-Product Attention". The input consists of queries and keys of dimension $d_k$, and values of dimension $d_v$. We compute the dot products of the query with all keys, divide each by $\sqrt{d_k}$, and apply a softmax function to obtain the weights on the values.

Core Equation Eq. (1)
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
1 Matrix Multiplication ($QK^T$)
Computes the pairwise compatibility scores between all queries and keys. For a sequence of length $n$, multiplying $Q \in \mathbb{R}^{n \times d_k}$ with $K^T \in \mathbb{R}^{d_k \times n}$ yields an $n \times n$ attention matrix measuring mutual token resonance.
2 Variance Scaling ($\frac{1}{\sqrt{d_k}}$)
If query and key components are independent random variables with mean $0$ and variance $1$, their dot product has mean $0$ and variance $d_k$. For large $d_k$, the dot products grow exceedingly large in magnitude, pushing softmax into regions with vanishing gradients! Scaling by $\sqrt{d_k}$ restores unit variance.
3 Softmax Normalization
Applies $\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$ row-wise to convert unbounded raw similarity logits into a rigorous probability distribution that sums to $1.0$.
4 Value Aggregation ($\times V$)
Multiplies the attention distribution matrix by $V \in \mathbb{R}^{n \times d_v}$. Each output row is a context-weighted convex combination of value representations across the entire sequence.
💡
Why Dot-Product over Additive Attention? While additive attention yields comparable performance, dot-product attention can be implemented using highly optimized BLAS matrix multiplication routines, making it drastically faster and more space-efficient in hardware.

In practice, we compute the attention function on a set of queries simultaneously, packed together into a matrix $Q$. The keys and values are also packed into matrices $K$ and $V$.

3. Multi-Head Attention

Instead of performing a single attention function with $d_{model}$-dimensional keys, values and queries, we found it beneficial to linearly project the queries, keys and values $h$ times with different, learned linear projections to $d_k$, $d_k$ and $d_v$ dimensions, respectively.

Multi-head attention allows the model to jointly attend to information from different representation subspaces at different positions. With a single attention head, averaging inhibits this.

Subspace Projections Eq. (2)
$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h)W^O$$ $$\text{where } \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$
1 Parameter Projection Matrices
The projections are parameter matrices: $W_i^Q \in \mathbb{R}^{d_{model} \times d_k}$, $W_i^K \in \mathbb{R}^{d_{model} \times d_k}$, $W_i^V \in \mathbb{R}^{d_{model} \times d_v}$, and $W^O \in \mathbb{R}^{hd_v \times d_{model}}$.
2 Hyperparameter Choices
In the canonical Transformer: $h = 8$ parallel attention layers (heads). For each head, $d_k = d_v = d_{model}/h = 512 / 8 = 64$. Due to the reduced dimension of each head, total compute is similar to single-head attention with full dimensionality.
🧠
Subspace Diversity: One head can focus on syntactic dependencies (e.g. subject-verb matching), another on anaphora resolution (e.g. pronouns to antecedents), and another on punctuation or semantic sentiment.

4. Positional Encoding

Since our model contains no recurrence and no convolution, in order for the model to make use of the order of the sequence, we must inject some information about the relative or absolute position of the tokens in the sequence. To this end, we add "positional encodings" to the input embeddings at the bottoms of the encoder and decoder stacks.

Sinusoidal Signal Eq. (3) & (4)
$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$ $$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$
1 Wavelength Spectrum
The wavelengths form a geometric progression from $2\pi$ to $10000 \cdot 2\pi$. The lower dimensions oscillate rapidly (capturing local relative distances), while higher dimensions oscillate slowly (capturing global macro structure).
2 Linear Relative Shift Property
For any fixed offset $k$, $PE_{pos+k}$ can be represented as a linear function of $PE_{pos}$ via angle sum identities: $\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta$. This enables the self-attention layer to easily learn to attend by relative positions!
📐
Extrapolation to Unseen Lengths: Unlike learned positional embeddings which fail completely when encountering sentences longer than seen during training, sinusoidal functions extrapolate naturally to arbitrary sequence lengths.

5. Residual Connections & Layer Normalization

Each sub-layer (multi-head attention or feed-forward network) in each encoder and decoder layer is wrapped with a residual connection, followed by layer normalization. That is, the output of each sub-layer is:

Sub-layer Wrapper Eq. (5)
$$\text{Output} = \text{LayerNorm}(x + \text{SubLayer}(x))$$ $$\text{where } \text{LayerNorm}(z) = \frac{z - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta$$
1 Residual Gradient Highway
The skip-connection ($x + \text{SubLayer}(x)$) ensures the gradient operator $\frac{\partial \mathcal{L}}{\partial x}$ contains an identity term $+1$, preventing vanishing gradients even when stacking dozens of transformer layers.
2 LayerNorm vs BatchNorm
Batch normalization computes statistics across batch examples (which struggles with variable sequence lengths). Layer normalization normalizes across the feature dimension for each token independently, making it invariant to batch size.

6. Conclusion

In this work, we presented the Transformer, the first sequence transduction model based entirely on attention, replacing the recurrent layers most commonly used in encoder-decoder architectures with multi-headed self-attention.

For translation tasks, the Transformer can be trained significantly faster than architectures based on recurrent or convolutional layers. On both WMT 2014 English-to-German and WMT 2014 English-to-French translation tasks, we achieve a new state of the art.
